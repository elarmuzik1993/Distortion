Sledge Distortion - Linux (VST3, x86_64)

Install (current user):   ./install.sh
Install (all users):      sudo ./install.sh --system
Another folder:           ./install.sh --dir /path/to/vst3
Upgrade:                  run install.sh again; it replaces the old bundle.
Uninstall:                ./uninstall.sh   (add --system, --dir or --purge as needed)

Or copy "Sledge Distortion.vst3" by hand into ~/.vst3 (or /usr/lib/vst3).
Then rescan plug-ins in your host.

Presets, settings and imported NAM profiles live in
~/.config/Monolit Beatz/Sledge Distortion and are kept on upgrade and uninstall.
