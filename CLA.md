## Why it exists

The project depends on JUCE, which is offered either under paid terms or the GPL
v3. This project takes the GPL route. If that ever has to change — a commercial
JUCE licence, a dual-licensed edition, a different framework — every line of code
in the project has to be relicensable.

Without this agreement, one contribution from someone who later becomes
unreachable would freeze the project's licence permanently. This keeps that door
open. It is insurance, not a plan.

## How to agree

**Opening a pull request means you agree to this document.** The pull request
template has a checkbox as a reminder; ticking it records that you read this. No
signature, no bot, no account to create.

If you would rather not agree to the relicensing clause, say so in the pull
request. Small fixes — typos, documentation, a one-line correction — are not worth
anyone's paperwork, and I would rather have the fix.
